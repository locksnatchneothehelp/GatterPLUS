Steuerung & Tastenkürzel

Überblick

Bauteile werden aus der Leiste oben auf das Whiteboard gezogen und rasten dort auf dem Punktraster ein. Verbunden wird mit dem Werkzeug „Verkabeln“: auf einen Ausgang klicken, das Kabel über das Raster führen und auf einen Eingang klicken. Der Power-Knopf oben rechts oder die Taste S startet die Simulation, danach lassen sich die Schalter per Klick umschalten. Grüne Leitungen führen eine 1, graue eine 0.

Leitung anklickenauswählen; Punkte ziehen = verschieben, Doppelklick auf Punkt = entfernen, Doppelklick auf Leitung = Punkt einfügen
Verkabeln: Klick auf eine LeitungAbzweig von dieser Leitung starten
Verkabeln: Start an einem EingangLeitung rückwärts zu einem Ausgang ziehen
